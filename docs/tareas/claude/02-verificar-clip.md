# 02 · Contrastar el primer clip con un conteo manual

**Disponible · 6 de noviembre.** Trabajá desde la rama `tareas-03-04-panel-informe`, que contiene el panel Docker y el informe. La predicción está publicada en `origin/vision`. El objetivo es verificarla de extremo a extremo contra la referencia manual ya registrada.

1. **Prepará los insumos.** Revisá `git status -sb`, ejecutá `git fetch origin vision` y registrá `git rev-parse origin/vision`. Sin cambiar de rama ni fusionar, extraé desde ese commit los archivos `evaluation/results/oficina-00-06-prediccion.json` y `oficina-00-06-prediccion.config.json` de la misma carpeta. Guardá copias UTF-8 en `docs/relevo/2026-11-06-claude-tarea02/`. La referencia manual local es [oficina-00-06-manual.json](../../demo/oficina-00-06-manual.json). Conservá los tres insumos originales.
2. **Contrastá los cruces.** En el [video de oficina](https://www.youtube.com/watch?v=L1fkyVQbHOg), usá 0–6 s y solo la vista superior derecha. Abajo → arriba es subida. Compará por sentido y tiempo, un evento manual por predicción, con tolerancia ±1 s. Registrá esperado, observado, diferencia y cualquier evento extra u omitido. La referencia manual es aproximada (2 y 4 s); el JSON revisado contiene 2,16 y 4,60 s. Los IDs pueden cambiar entre ida y vuelta. Si no conseguís reproducir el video, indicá que contrastaste los archivos y dejá pendiente solo la revisión visual.
3. **Probá la API real.** Desde la raíz ejecutá `docker compose up --build -d`. Enviá el JSON **predicho completo** a `http://127.0.0.1:8001/ocupacion` por POST con Content-Type application/json. Guardá la respuesta. Con carga inicial 0 y capacidad 20 se espera una parada con una subida, una bajada, cero pasajeros, 0 % y ningún aviso.
4. **Probá el panel.** En `http://127.0.0.1:8502` cargá la misma predicción. Mové el selector a 0, 2,16 y 4,60 s: deben verse respectivamente 0, 1 y 0 pasajeros (0 %, 5 % y 0 %). Contrastá indicadores, tabla y gráfico, y guardá los valores observados con capturas. Si el commit contiene tiempos diferentes, usá sus tiempos reales y documentá la diferencia.
5. **Devolvé la evidencia.** En el README de la carpeta de relevo dejá commit de origen, comandos, comparación manual, respuesta HTTP, capturas y discrepancias. Identificá este resultado como ensayo de integración del detector base con ByteTrack calibrado, según el archivo de configuración. La reproducción local de la inferencia y la evaluación en grabaciones independientes son comprobaciones distintas. Actualizá `resumen.md` con el resultado real y dejá los cambios sin commit para revisión.
